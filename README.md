# vrc-map-comments

[VRC 地图图鉴](https://github.com/LigeLoveRosita/main-vrc) 的 **评论** 数据仓库。

站点直接读取 `data/comments.json`。**改这里的内容，刷新网页即刻生效，不需要重新部署站点。**

## 文件

| 文件 | 内容 |
| --- | --- |
| `data/comments.json` | 全部评论 |

## 格式

```json
{
  "version": 1,
  "updatedAt": "2026-09-15T12:00:00Z",
  "comments": [
    {
      "id": "c-0001",
      "mapId": "the-great-pug",
      "author": "昵称",
      "stars": 5,
      "body": "评论内容",
      "at": "2026-08-01T12:25:00Z",
      "likes": 12
    }
  ]
}
```

### 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | **必须唯一**。手写推荐 `c-0001` 递增；自动生成的是随机串 |
| `mapId` | 是 | 对应 `vrc-map-ratings/data/maps.json` 里的地图 `id` |
| `author` | 是 | 显示用昵称，不做账号校验 |
| `stars` | 否 | 1–5 整数；`null` 表示只评论不打分 |
| `body` | 是 | 评论正文，站点上限 600 字 |
| `at` | 是 | ISO 8601 UTC 时间，例如 `2026-09-15T12:00:00Z` |
| `likes` | 否 | 点赞数，默认 `0` |

## 三种提交方式

1. **在网页上提交** — 地图详情页写评论，再到「我的」页点同步，会生成预填 JSON 的 Issue
2. **直接提 PR** — 按上面格式追加到 `comments` 数组
3. **开 Issue** — 打上 `data-sync` 标签

## 内容建议

- 聚焦在地图本身：值不值得去、什么时间段最好、有没有踩坑
- 涉及剧透的（尤其恐怖解谜类地图）请先在正文开头加一行 `⚠ 含剧透`
- 维护者保留删除广告、人身攻击、与地图无关内容的权利
